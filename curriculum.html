LEARNING MAP

基礎から実装へ、段階をつくる。

  1. 01 / PYTHON

    プログラミングの基礎

    変数・データ型、データ構造、条件分岐、関数。後の分析コードを読むための土台をつくる。

  2. 02 / DATA

    データを理解する

    データの性質と前処理を学び、分析に使える形に整える。

  3. 03 / MACHINE LEARNING

    学習・予測・評価

    回帰・分類、クラスタリング・主成分分析。モデルの出力を評価し、比較する。

  4. 04 / DEEP LEARNING

    ニューラルネットワークの原理

    基本構造と学習の仕組みを、図や数式と結び付けて理解する。

  5. 05 / PYTORCH

    モデルを実装する

    Tensorの基礎から回帰・分類モデルの構築、学習、精度改善へ進む。

  6. 06 / APPLICATION

    応用分野へ広げる

    画像認識や自然言語処理など、データの種類に応じた手法へ展開する。

LESSON DESIGN

実装と結果を照合

講義、課題、模範解答を分けて構成。講義で処理の意味を理解し、課題で自分のコードを書き、解答と比べて理解を確かめる流れを設計しました。

講義 / Markdown中心説明とコード例を交互に配置

用語や数式の説明に続けてコード例と出力例を示し、処理の意味を一段ずつ追えるようにしています。

演習 / コードセル大きな課題を小問に分解

準備済みのデータや手順を起点に、複数の小問へ進む形式。回答用のコードセルを設け、実装する箇所を明確にしています。

NOTEBOOK STRUCTURE

一つの講義の中にも、小さなステップを。

01

何を学ぶか

導入・目次・前提知識の振り返りで、今回の到達点を示す。

02

仕組みを理解する

概念図と数式を用い、モデルや処理の関係を説明する。

03

データを準備する

読み込み、項目の確認、前処理、学習・評価用の分割へ進む。

04

コードで実装する

モデル定義、学習、予測を分け、各処理のコード例を示す。

05

結果を読み取る

評価指標、比較表、グラフから、性能と改善点を考える。

06

演習で確かめる

要点を整理したあと、課題と模範解答で理解を確認する。

TWO LEARNING PATHS

分析と深層学習を、実装の順序で説明する。

データ分析 / 回帰の例データから、予測の評価まで

データ確認 → 前処理・分割 → モデル学習 → 予測 → 指標による比較 → 散布図の読み取り

複数の回帰モデルを比較し、数値だけでなく可視化からも結果を考察する構成です。

深層学習 / PyTorchの例モデルの定義から、学習の検証まで

データ準備 → Dataset・DataLoader → ネットワーク定義 → 損失関数・最適化 → 学習・検証 → 最終評価

学習時の誤差推移を確認し、モデル内部の処理と出力のつながりを理解する構成です。

VISUAL EXPLANATION

図・表・コードに、それぞれ役割を持たせる。

概念図構造と処理の関係をつかむ

ネットワークの構造や学習の流れなど、文章だけでは追いにくい関係を視覚化。

グラフ変化や傾向を読み取る

誤差の推移、予測値と実測値の関係などを示し、結果の考察へつなげる。

比較表手法の違いを整理する

複数モデルの評価指標を並べ、何を基準に比較するのかを明確にする。

コード例・出力例操作と結果を対応させる

処理単位でコードと出力を示し、どの操作で何が得られるかを確認する。
